# RockChopper
# ⛏️ Rock Chopper  A retro pixel-art browser RPG. Play as **Neil** (All-Rounder), **Xavier**, or **Carter**, chop rocks across **11 rarity tiers** (Common to Apex Purple), battle wildlife, and upgrade pickaxe materials at Hudson's Shop.  **Play:** Open https://dargudargarehh-tech.github.io/RockChopper/ in any browser. Move with `WASD`/Arrows/D-Pad; chop with `Space`/Click.
